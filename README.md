# TeamFlow App

A full-stack productivity web application for managing tasks, notes, and reminders with user authentication, offline local caching, dark/light theme, and customizable sound notifications.

## Project Structure

- **client/**: React + Vite frontend with Tailwind CSS and Lucide icons.
- **server/**: Node.js + Express backend with MongoDB (Mongoose) and JWT authentication.

## Quick Start

### Client
```bash
cd client
npm install
npm run dev
```

### Server
```bash
cd server
npm install
npm run dev
```
